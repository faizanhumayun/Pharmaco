=====================================================================
  PHARMACO FOR THE SHOP'S COMPUTER (WINDOWS)
  Installation and day-to-day guide
=====================================================================

The shop's main computer runs Pharmaco and keeps the real books, so the
counter works with no internet. The other computers in the shop open it
over the shop's own network. When there is internet, the main computer
sends a copy of the books to the online site every five minutes. The
owner can read that copy from anywhere, and it is also how the books are
recovered if this computer is lost, stolen or broken.

    MAIN COMPUTER (this kit)               ONLINE SITE
    Pharmaco + its database   -- every 5 min, when online -->  read-only copy
    the real books                                            (owner reads it)
         ^
         |  shop network (no internet needed)
    other counters / laptops

---------------------------------------------------------------------
STEP 1  On the online site: register the shop  (once per shop)
---------------------------------------------------------------------

Done by the App Owner, in the back office of the online site.

 1. Back office -> Shop copies -> Register a shop. A name is all it needs.
 2. It shows two values. Keep them for Step 2:

        MIRROR_PUSH_URL=https://<online site>/mirror/receive
        MIRROR_PUSH_TOKEN=<a long code>

    Lost them? "Show token" beside the shop shows the same token again
    (nothing changes). "New token" makes a different one, and the old
    one stops working at once.

You can skip this step and add the two values later (see Step 5).


---------------------------------------------------------------------
STEP 2  On the main computer: install
---------------------------------------------------------------------

Choose the computer that is switched on whenever the shop is open. The
kit carries everything (PHP, the MariaDB database, the application), so
no internet is needed to install.

 1. Copy pharmaco-shop-windows.zip to the computer (USB drive or a link).
 2. Right-click it -> Extract All. The Desktop is fine.
    (Do not run the installer from inside the zip without extracting it.)
 3. Open the extracted folder and double-click "Install Pharmaco".
    Click Yes when Windows asks for administrator rights.
 4. It asks for two values: paste MIRROR_PUSH_URL and MIRROR_PUSH_TOKEN
    from Step 1. Or leave both empty to set up the online copy later.
 5. Wait for "Pharmaco is installed." It opens the browser at
    http://pharmaco:8080 and prints the address the other computers
    should use, for example http://192.168.1.20:8080. Write that down.
    (http://localhost:8080 opens it too, on this computer.)

What it set up:
  - Everything in C:\Pharmaco
      C:\Pharmaco\app       the application and its settings (.env)
      C:\Pharmaco\data      the database: THE BOOKS
      C:\Pharmaco\logs      server.log and scheduler.log
  - The database as a Windows service, "PharmacoDB" (port 3307).
  - "Pharmaco Server", which starts with the computer (port 8080).
  - "Pharmaco Scheduler", every minute: sends the online copy, writes
    backups, listens for a pause from the back office, and restarts the
    server if it has stopped (after sleep, for example).
  - Port 8080 opened in the Windows firewall for the shop's network.
  - The name "pharmaco" for this computer, so the browser opens
    http://pharmaco:8080 (one line in Windows' hosts file). It works on
    this computer only; others use the address with the numbers.
  - Desktop shortcuts: "Pharmaco", and "Pharmaco Till (prints directly)"
    when Chrome or Edge is installed.


---------------------------------------------------------------------
STEP 3  First sign-in and setting up the business
---------------------------------------------------------------------

 1. Open http://pharmaco:8080/back-office/login and sign in with the
    built-in back-office login (the App Owner's).
 2. Change its password straight away (Profile). Every installation
    starts with the same one.
 3. Then either:
      a) A NEW shop: create the business, add the owner and operators,
         bring in companies and products, and finalise the opening
         balance as usual.
      b) A REPLACEMENT computer for a shop that already has books online:
         do NOT create anything. Restore the books instead. See "If this
         computer is lost, stolen or broken" below.

Importing an old POS .mdb file: Windows cannot read .mdb files itself.
Convert it first on a Mac or Linux machine that has the project:
    php artisan oldpos:convert "posdbase.mdb"
and upload the posdbase.pharmaco.json it writes on the import page.


---------------------------------------------------------------------
STEP 4  The other computers in the shop
---------------------------------------------------------------------

 1. In the router, give the main computer a fixed IP address, so the
    address from Step 2 never changes.
 2. On each other computer, open that address in Chrome or Edge, for
    example http://192.168.1.20:8080, and bookmark it.
 3. Nothing is installed on them, and they need no internet, only the
    shop's network.
 4. On each computer, click "Name this device" at the top of the screen
    and give it a name ("Counter 2", "Laptop"). Records show which
    computer they were entered on.

One person is signed in on one computer at a time. Signing in somewhere
new signs that person out of the other computer.

The main computer must stay on while anyone is working.


---------------------------------------------------------------------
STEP 5  Check that the online copy is being sent
---------------------------------------------------------------------

The bar at the top of every screen says where things stand:
    Online - synced          all good
    Online - sync pending    something is not sent yet; press "Sync now"
                             or wait up to five minutes
    Offline                  no internet; the shop keeps working, and the
                             copy is sent when the internet comes back
Hover over it to see the reason when something is wrong.

Adding or changing the two values after installing:
 1. Open C:\Pharmaco\app\.env in Notepad (run Notepad as administrator).
 2. Set the two lines:
        MIRROR_PUSH_URL=https://<online site>/mirror/receive
        MIRROR_PUSH_TOKEN=<the token>
 3. Save. Nothing needs restarting; the next send uses them.

On the online site, Back office -> Shop copies shows when the last copy
arrived, or why it failed. The owner signs in at the online site with the
same email and password as in the shop, and sees the business read-only.


---------------------------------------------------------------------
PRINTING SLIPS WITH NO PREVIEW
---------------------------------------------------------------------

Use the "Pharmaco Till (prints directly)" shortcut at the counter, and
make the slip printer the Windows DEFAULT printer. Print then goes
straight to it. The first time, that window asks you to sign in once
(it keeps its own browser profile in C:\Pharmaco\till-browser).


---------------------------------------------------------------------
BACKUPS
---------------------------------------------------------------------

Every copy sent online is also a full backup on this computer. The last
14 are kept in:
    C:\Pharmaco\app\storage\app\private\mirror\out
    (files named books-YYYY-MM-DD-HHMMSS.jsonl.gz)

 - Copy that folder to a USB drive now and then, and keep it away
   from the computer.
 - To make a backup now without sending it (see "Commands"):
       artisan mirror:push --local
 - To keep more than 14, add MIRROR_KEEP_SNAPSHOTS=30 to the .env file.


---------------------------------------------------------------------
IF THIS COMPUTER IS LOST, STOLEN OR BROKEN
---------------------------------------------------------------------

The online site holds the books as of the last copy that reached it, so
at most the last few minutes before the computer went offline are lost.

 1. On the online site: Back office -> Shop copies -> "Download books"
    beside the shop. Keep the file it gives you:
        books-<shop>-<date>.jsonl.gz
    (A file from the USB backup works too.)
 2. Also press "Show token" and keep the token: the SAME token is used
    on the new computer.
 3. Install on the new computer (Step 2). When asked for the two values,
    leave BOTH EMPTY for now.
 4. Copy the books file to the new computer, for example to C:\books\.
 5. Open Command Prompt as administrator (see "Commands") and run:
        cd /d C:\Pharmaco\app
        C:\Pharmaco\runtime\php\php.exe artisan mirror:restore C:\books\books-<shop>-<date>.jsonl.gz
    Answer "yes". It replaces everything in this computer's database
    with the file, and says how many rows it restored.
 6. Sign in with the built-in back-office login (Step 3). The restore
    keeps this computer's own back-office login and password. The shop's
    owner and operators sign in with their usual email and password.
 7. Now add the two values to C:\Pharmaco\app\.env (Step 5) using the
    token from point 2. Within five minutes the online copy is being
    sent from the new computer.

Why the values are left empty until the restore: an empty new computer
must never send its empty books. (The online site refuses them anyway
and says so under Shop copies.)

If the shop was paused for a fix when the computer was lost: the
downloaded file already contains the fix. After the restore, the back
office chooses "Give up the fix and reopen the shop".


---------------------------------------------------------------------
WHEN THE BACK OFFICE PAUSES THE SHOP FOR A FIX
---------------------------------------------------------------------

Sometimes support has to correct something in the books. The books can
only be entered in one place at a time, so:

 1. Support switches the shop off in the back office.
 2. Within a minute or two this computer sends its last entries and
    LOCKS. Every screen says "We are fixing an issue" with the support
    phone number. Nothing can be entered, on purpose.
 3. When support switches the shop back on, the corrections come back
    to this computer, are checked, and it opens by itself.

This computer must be ONLINE for both the pause and the return. If it
stays locked, check the internet and call the support number.


---------------------------------------------------------------------
UPDATING TO A NEWER KIT
---------------------------------------------------------------------

 1. Get the new pharmaco-shop-windows.zip and extract it.
 2. Double-click "Install Pharmaco" again.
 3. It replaces the application and KEEPS the books, the settings (.env)
    and the backups. It asks no questions on an update.

Update the online site at the same time: the shop's computer and the
online site should run the same version.


---------------------------------------------------------------------
COMMANDS (FOR SUPPORT)
---------------------------------------------------------------------

Open: Start -> type cmd -> right-click "Command Prompt" -> Run as
administrator. Then:

    cd /d C:\Pharmaco\app

and run any of these (php is C:\Pharmaco\runtime\php\php.exe):

    ...\php.exe artisan mirror:push --force
            send the online copy now, and print what happened
    ...\php.exe artisan mirror:push --local
            write a backup now, send nothing
    ...\php.exe artisan mirror:restore <file>
            put the books back from a backup or a downloaded file
    ...\php.exe artisan ledger:verify
            check that the books add up

What mirror:push --force prints:
  "Sent. The online copy is up to date."
        Working.
  "Not sent: MIRROR_PUSH_URL and MIRROR_PUSH_TOKEN are not set"
        Add the two values to C:\Pharmaco\app\.env (Step 5).
  "The platform could not be reached" + a reason
        "Could not resolve host": the address is mistyped, or there is
        no internet. "SSL certificate": install a newer kit.
  "The platform did not accept the snapshot" + a reason
        "token is not recognised": wrong token; use "Show token" under
        Shop copies. "This computer has no businesses": restore the
        books first (see "lost, stolen or broken"). Anything else:
        send the reason to support.


---------------------------------------------------------------------
PROBLEMS AND WHAT TO DO
---------------------------------------------------------------------

Pharmaco does not open on this computer
  - Wait a minute: the scheduler restarts the server by itself.
  - Still not: restart the computer.
  - Then look at C:\Pharmaco\logs\server.log.

Other computers cannot open it
  - Is the main computer on, and on the same network?
  - Is the address right? Its IP may have changed; give it a fixed IP
    in the router (Step 4).
  - Another firewall or antivirus may block port 8080: allow it there.

The bar says "sync pending" for a long time
  - Check the internet, then run mirror:push --force (Commands) and
    read what it says.

The installer stopped with "STOPPED: ..."
  - Nothing after that point was changed. Fix the cause it names and
    run the installer again.

Many computers working at once feel slow
  - The kit's built-in web server answers one request at a time. That
    is fine for a counter or two and the owner. A bigger shop should
    be moved to a full web server; ask support.


---------------------------------------------------------------------
UNINSTALLING
---------------------------------------------------------------------

"Uninstall Pharmaco" stops Pharmaco starting with the computer and
removes the shortcuts and the firewall rule. It deliberately leaves
C:\Pharmaco and the database service, because they hold the books.
Take a backup (see "Backups") before removing anything by hand.
